# Model Failure Analysis

Known Phase 1 risks include copper-like reflections, tiny contaminants, merged adjacent objects, occlusion-driven centroid identity changes, boundary aliasing, blur and exposure failures, and unknown materials outside the three-class supervised vocabulary. Phase 2 adds decision explanations and camera-health signals, but no real-factory acceptance claim is made. Real-data false positives/negatives require a redistributable subset or private site dataset and reviewer adjudication.
